# Week 8 corpus (Spanish data)

[Glossary](../glossary.md) · [Week 8 README](../../semana-08/README.md)

This page describes the week 8 data that sits outside a folder with its own README: the Spanish document corpus in
`corpus/`. The gold set and the results have their own READMEs ([datasets](../../semana-08/datasets/README.md),
[resultados](../../semana-08/resultados/README.md)).

The corpus is the document base of a fictional Mexican distributor: policies, procedures and operating guides on
returns, purchasing, suppliers, the reorder policy, distribution centers, cycle counts and similar topics. Part of it
was copied unchanged from the inventory-copilot project and part was written for this week (the week 8 README gives
the split). The gold passages in `datasets/` are exact sentences from these files.

`corpus/` has no README of its own on purpose: the week 8 scripts, and several scripts of weeks 9 to 12, load every
`*.md` file in that folder. A README there would join the corpus and change every measurement that uses it.

**Why it is in Spanish:** the lab measures retrieval and RAG over Spanish documents. Translating the corpus would
change what was measured, and the gold passages must match it word for word.
