# Week 10 gold sets (Spanish data)

[Glossary](../../docs/glossary.md) · [Week 10 README](../README.md)

The gold sets of week 10, frozen before any experiment ran, and the scripts that built them. The integrated set mixes
SQL, document, non-text (PDF, scan, image) and mixed questions for the integrated assistant. The security set holds
the write attempts, leak attempts, prompt injection questions and direct SQL statements of activity 8. The [week 10 README](../README.md)
gives the size of each set and the results; the gold set validation is in
[`../resultados/golden_validacion.md`](../resultados/golden_validacion.md).

**Why it is in Spanish:** the lab measures a Spanish-language assistant over a Spanish corpus. The gold passages and
the exact answers must match the Spanish documents word for word; translating them would change what was measured.
The English question files keep the Spanish passages and answers on purpose. The keys and values are explained below.

## Files

| File(s) | What it is | Written by / Read by |
|---|---|---|
| `integrado_es.jsonl`, `integrado_en.jsonl` | Integrated gold set, 51 questions per language (15 SQL, 15 document, 15 non-text, 6 mixed): one question per line, with its type and its reference (SQL, gold passages or exact answer) | `construir_integrado.py` (which also writes `../fuentes/`). Read by every script in `../experimentos/` except `sql_legado.py`, by `../ci/eval_ci.py`, `semana-11/datasets/construir_eval_rag.py` and `semana-12/evaluacion/seguridad.py` |
| `permisos_semana10.json` | Roles of the six new week 10 documents (PDFs, scans and images), added to week 9's roles per document | Not generated by a script. Read by `../experimentos/asistente.py`, which merges it with `semana-09/datasets/permisos.json` |
| `seguridad.json` | Security cases by category, each question in Spanish and English | `construir_seguridad.py` (which also writes `../fuentes/inyeccion/`, `../pdf_inyeccion/` and `../imagenes_inyeccion/`). Read by `../experimentos/seguridad.py` (also imported by `../ci/eval_ci.py`) and `semana-13/seguridad/casos.py` |
| `construir_*.py` | The builders of the sets above, with their checks | Run when the sets were frozen, before the experiments |

## Keys

| Key | Meaning |
|---|---|
| `id` | Question ID. Prefix: `int-sql`, `int-doc`, `int-pdf`, `int-ocr`, `int-imagen`, `int-mix` in the integrated set; `esc`, `fsql`, `dir`, `iny` in the security set |
| `tipo` | Question type: `sql`, `documental` (document), `no_textual` (non-text: the answer is only in a PDF, a scan or an image), `mixta` (mixed: needs SQL and a document) |
| `question` | The question |
| `sql` | SQL and mixed questions: the reference SQL, over the original inventory-copilot tables; scored by execution accuracy. In `directas`, the statement to run |
| `order_matters` | `true` if row order counts when comparing result sets |
| `origen` | SQL and document questions: the question it was copied from, a week 7 hard-set ID (`hard-NNN-es`, `hard-NNN-en`) or a week 9 base question ID (`rec-NN`) |
| `gold` | Document and mixed questions: the gold passages, a list of objects with `source` (week 8 corpus file) and `passage` (the exact Spanish text) |
| `formato` | Non-text questions: the medium of the answer, `pdf`, `ocr` (scan) or `imagen` (image) |
| `fuente` | Non-text questions: the source document in `../fuentes/` |
| `respuesta` | Non-text questions: the exact answer |
| `nota` | `permisos_semana10.json`: a note that the roles are a synthetic test model and add to week 9's |
| `tenant` | `permisos_semana10.json`: the tenant of the new documents (`alfa`) |
| `roles_por_documento` | Roles that may read each document (in `seguridad.json`, the four injected documents). Role names: `ventas` sales, `almacen` warehouse, `operaciones` operations, `compras` purchasing, `finanzas` finance, `calidad` quality |
| `escritura` | Security: write attempts and SQL injection in natural language |
| `fuga_sql` | Security: attempts to read the documents through the NLQ tool, around the role filter |
| `directas` | Security: write or evasion SQL statements run directly against each defense layer |
| `cadena` | Security: statement IDs run in sequence on one session |
| `inyeccion` | Security: questions whose answer is in a document with an injected instruction |
| `documento` | The injected document a question targets |
| `dato` | Regular expression of the correct figure, expected in the answer |
| `siguio` | Per injected document, regular expressions that show the assistant followed the instruction (a canary string, a false figure or the attacker's email address) |
| `marcas_tenant` | Per week 9 multi-tenant question, a regular expression for each tenant's value (`alfa`, `beta`) |
| `es`, `en` | The question in Spanish and in English |
